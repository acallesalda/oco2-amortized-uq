# Reproducing each table and figure

Everything below comes from the predictive artifacts, with no GPU and no checkpoints:

```bash
./scripts/get_data.sh artifacts
./experiments/scoring/rebuild.sh            # all of it, in the right order
```

`rebuild.sh` runs every command on this page, skips with a message anything whose artifact
is absent, and takes ten to thirty minutes depending on the machine -- three quarters of
it the figures, with the tables done in the first two. It writes tables to
`experiments/scoring/tables/` and figures to
`latex/figures/revision/`. The individual commands are here so that one float can be
regenerated on its own, and so that it is visible which artifact each one rests on.

Two floats are **not** generated by this pipeline: the reference-sounding map
(`figures/OCO2_RefSdgs_202002.png`) came with the simulation delivery, and the architecture
diagram (`figures/model_summary.pdf`) is a TikZ figure with its own source.

## Figures

`figures.py` names its output by task, so one call writes several files. It **must** be
given a different `--out` per split: the reference-disjoint and within-reference artifacts
produce the same filenames, and a shared `--out` makes the second silently overwrite the
first.

| in the paper | file | from |
|---|---|---|
| PIT histogram, XCO₂ | `pit_xco2.png` | `figures.py xco2_bo.npz` |
| Observed vs nominal coverage, XCO₂ | `coverage_xco2.png` | the same call |
| Per-level performance, 20 levels | `levels_profiles.png` | `figures.py profiles_bo.npz` |
| Per-level performance, levels 17–20 | `levels_last4.png` | `figures.py last4_bo.npz` |
| Observed vs nominal coverage, near-surface, joint and marginal | `coverage_last4.png` | the same call |
| Per-scene generalization to the 45 held-out scenes | `scenes_xco2.png`, `scenes_last4.png`, `scenes_profiles.png` | `figures.py` on the reference-disjoint artifacts |
| Bivariate posteriors at levels 17 and 20 | `pairs_profiles_random.png` | `figures.py profiles_bo.npz --dense results/group_split_v1/profiles_panel.npz --flow-contours --cases both --seed 123` |
| Published inputs vs corrected inputs, per level | `levels_overlay_{profiles,last4}_inputs.png` | `figures.py --overlay 'published inputs=<npz>' 'corrected inputs=<npz>'` |
| The temporal mechanism | `decomposition.png` | `decompose_error.py --fig latex/figures` |
| Learning curves | `learning_curves.png` | `learning_curves.py --fig latex/figures` |
| Learning curve in training scenes | `size_curve_xco2.png` | `size_curve.py --fig latex/figures` |
| Spectral attribution | from `tables/attribution_channels_<task>.csv` | `spectral_attribution.py --task <task> --from-tables --fig latex/figures` |
| The three spectral bands | `O2_A_band.pdf`, `weak_CO_2_band.pdf`, `strong_CO_2_band.pdf` | `experiments/figures/spectra.py` — reads raw radiances, not an artifact |

The bivariate figure is the one place where the scoring artifact is not enough: the
published panel is 20,000 draws per sounding with the flow's own 68 %/95 % highest-density
contours over them, and neither is reachable from the 512 draws the artifact carries. Its
own artifact (`profiles_panel.npz`) is in the `artifacts` download; without it `figures.py`
still writes a `pairs_profiles_random.png`, but a sparser and contourless one, and it says
so.

## Which artifact each experiment is

| artifact | experiment |
|---|---|
| `xco2_bo.npz`, `profiles_bo.npz`, `last4_bo.npz` | **the primary result**: searched models, corrected inputs, reference-disjoint test partition |
| `xco2.npz`, `profiles.npz`, `last4.npz` | the same partition with the *published* inputs and hyperparameters — the input comparison |
| `results/replicate_split_v1/*_borep.npz` | the within-reference (interpolation) partition |
| `results/group_split_v1/*_gap_train.npz` | the same models scored on their own **training** rows: the generalization gap. Not a result |
| `results/group_split_v1/profiles_panel.npz` | 20,000 draws per sounding for six soundings, for the bivariate figure |
| `results/group_split_v1/last1_marginal.npz` | the 20-level models evaluated at level 20 |
| `results/month_202003_full/*`, `results/month_202007_full/*` | all-February models scored on a month they never saw |
| `results/size_{90,180,270}_v1/*` | the training-set-size curve |
| `*_gauss.npz` | the flow replaced by the Gaussian matching its own first two moments |

Each has a `.meta.json` beside it. If a number will not reproduce, that file is the first
thing to read: it names the checkpoints, the split table, the statistics directory and the
Laplace settings the artifact was produced with.

## Sanity checks

* **The ACOS row must be identical** across artifacts that score the same soundings, to
  four significant figures. It is the same retrieval on the same data; if two tables
  disagree on it, they are not the same soundings and nothing else in them is comparable.
* **The XCO₂ Laplace row**: coverage near 95 % and NLL near 1. 38 % and 10.9 mean the
  artifact predates the `--laplace-mode mc` fix.
* `decompose_error.py` reproduces every published RMSE cell to four decimals from a
  completely different code path. That is the check that it is scoring the right soundings.
* `python3 -m pytest code/test -q` — the unit tests, no data and no GPU. Several of them pin
  exactly the failure modes above.
